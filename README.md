# LLM peer review inserted error benchmark

Code and prompts for “Large language models detect methodological errors that human peer review misses in randomized clinical trials.”

Dominikus Brian and Xavier Isidro Pereira Hernández contributed equally. The other authors are Hao Yin and Ruslan Rust. The preprint is being prepared for submission. This repository contains code and prompt templates only. Study data are supplied separately with the preprint.

## Reproduce the primary results

Use Python 3.10 or later. Install the dependencies and obtain the score file from Supplementary Data 1:

```bash
python -m pip install -r requirements.txt
python reproduce.py --scores /path/to/Supplementary_Data_1/validation/all_judge_item_scores.csv
```

The script writes per-model scores, sensitivity, control non-flagging, judge agreement and correlations to `results/`. It analyzes saved scores without calling model APIs.

Primary analyses average Fable 5 and Opus 5 rubric scores. Binary detection requires their mean to be at least 0.5. The alternative rule counts detection when either judge awards at least 0.5. Flags on control papers can be valid criticisms and are not independently adjudicated false positives. Historical point scores and binary detection rates are different measures.

## Original analyses and figures

`code/` contains the original analysis, figure, material-generation and model-runner scripts. `prompts/` contains the reviewer, judge and memory-probe instructions.

For the original analyses, copy `data/`, `data_original/` and `additional_judges/` from Supplementary Data 1 beside `code/`. Use `code/analyze_v2.py` for the primary score and detection summaries, `code/analyze_v17_checks.py` for the alternative detection rule, and `code/validate_release.py` for release consistency checks. Figures are generated by `code/make_figures_v17.py` and `code/make_suppfig_judges_v17.py`. The archive README identifies the other scripts and outputs. To regenerate timing and cost summaries, unpack Supplementary Data 2 into `logs/` beside `code/`.

Repeating model calls is separate from reproducing the analysis of saved outputs. The model-runner scripts use credentials supplied through the local environment; credentials are not included here.

## Data and interpretation

The source manuscripts, reviews, judge outputs, quotations, processed scores and session logs are packaged as Supplementary Data 1–3 for the accompanying preprint. The earlier exploratory run is separate from the primary experiment. These data are not hosted in this repository.

Judge names are explicit in the combined score table. Legacy J3 in the Kimi archive means Kimi K3. J3 and J4 in the decision-comparison archive mean Jev and Microsoft Decision-1, and J5 means GPT-6.1 Sol. These labels come from separate workflows.

The study contains three manuscripts per set. Repeated model sessions do not add independent manuscripts. Judge agreement measures scoring stability, not accuracy against independent human labels.
